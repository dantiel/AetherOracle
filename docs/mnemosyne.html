The memory cascade · four stages of living knowledge

Mnemosyne.
The Memory Cascade.

Knowledge does not reset between turns. Mnemosyne is a four-stage memory that runs underneath every conversation: the code itself, durable notes, transient fragments, and a polymorphic token substrate that makes all of it recallable by meaning.

▚ The four stages

Each stage holds a different half-life of truth — from the permanent structure of the repository down to thoughts that glow for an hour and decay.

⋈ Stufe 0 · Corpus graph

The repository itself. An Argonaut sounding extracts files and symbols into corpus_nodes / corpus_edges (imports, nesting, defines) and indexes every node into the token substrate. The code is recallable before the first note is ever minted.

▚ Stufe 1 · Durable notes

project_notes — the current-state memory. Notes carry tags, links and a context_path; they are written via remember and purged when reality moves on. Only what is true now belongs here.

⋄ Stufe 2 · Transient fragments

fragments — notes as metaformat with a TTL (default 3600 s). Freshly minted fragments glow in recall, expiring ones dim, and expired ones are lazily purged. Working thoughts, deltas, whispers — the change is flüchtig, the structure bleibt.

▚ Stufe 3 · Token substrate

memory_tokens — a polymorphic vector substrate shared by notes, fragments and corpus nodes. Three channels index each unit: content (tf-text), tags (explicit semantic anchors, compound tags split on _/-, default 2× weight) and path (structural trace).

◈ Resonance — the scoring machine

Every recall is scored by Resonance, not by keyword luck.

∿ Token scoring

Matches in the query score 4×/3×/2× by channel salience with a +5 path bonus; the cascade adds a local bonus (+6 in scope) and a distance-decayed whisper from ancestor scopes.

◈ Three lenses

:blend merges vector cosine and resonance scoring; :vector is pure cosine over the substrate; :resonance is the cascade-scoped ranking without vectors.

▚ Scope cascade

Notes in the current scope (+6) and ancestor scopes (distance-decayed) outrank foreign branches; child scopes whisper nothing upward — the parent observes only.

⌁ The promotion ladder

The documented ascent fragment → note → skill → axiom is being made live rung by rung.

◈ Rung 1 — implemented

Ouroboros lifts sync-markers that repeatedly glow around the same path into a durable structure note — the transient becomes permanent when it keeps happening.

◈ Rungs 2–3 — design

note → skill → axiom lives in protocol.md; the procedural precursor of a skill is companion_skill (steps, tools, output_type, refine_by), bound to a companion.
