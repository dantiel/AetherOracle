The orientation layer · where the oracle is between turns

Ægis.
The Living Orientation.

Memory without focus is noise. The Ægis is Mnemosyne's working orientation — a small, sharp shield of context carried between turns: what we are doing, where we are, and how deep the thought should run.

◇ What the Ægis holds

◈ tags

The focus areas of the current work — scored by resonance against every recall, so memory naturally gravitates toward what the Ægis names.

◈ summary

A required orientation sentence, rewritten every invocation — never appended. The Ægis is a living state, not a log.

◈ temperature & thinking

Dynamic agent state persisted until changed: temperature tunes responsiveness (0.0 for code, 1.0+ for creative work), thinking sets reasoning depth (fast … max).

◈ working_dir

Scopes the file listing and memory preferences to a subtree — the oracle's current room in the project.

◇ The Flash-Ægis rites

The Ægis can weave itself — when a distinct fast model exists (see Configuration). Without one, every rite degrades silently to the old behaviour: nothing is spent.

post_turn_sediment on by default

After each turn the kopist (fast model) distills SUMMARY + TAGS from what just happened and weaves them into the Ægis automatically. The orientation follows the work instead of waiting for a manual aegis invocation.

pre_turn_intent off by default

A pre-turn digest of the incoming prompt that re-points the Ægis before the deep mind reasons. Costs pre-turn latency; enable it only when rapid context-switching matters.

# .aethercodex
flash:
  enabled: true
  intent: false     # pre-turn digest (adds latency)
  sediment: true    # post-turn auto-weave

◇ Orientation discipline

The Ægis obeys the same current-state law as notes: it holds only what is true now. Historical traces belong to the chronicle (entries), not to the shield.
