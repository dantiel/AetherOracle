Metempsychosis.
Memory Across Contexts.

Every project has its own memory. Metempsychosis lets the soul travel: consult another task's notes, push knowledge into a remote context over ÆtherLink, spawn work there — or merge a whole context into your own orientation.

↯ The five rites

Consult from_task / query

Read the memory of another task by ID — the transmigration of knowledge between sibling workings in the same project.

Travel from_context

Query a peer's memory over ÆtherLink — the somersault cloud carries the question to another project and back.

Push to_context

Write notes into a remote context's memory. What you learned here can live there too.

Delegate create_task_in / invoke_in

Spawn a task on the peer, or execute a prompt there outright — the peer works with the combined memories of both contexts; the result returns marked as performed via metempsychosis.

Merge subscribe / unsubscribe

The deepest rite: the other context is merged into your Ægis orientation — the soul moves in, not just visits. unsubscribe releases it again.

The courier of these rites is Kintōun — the somersault cloud, first and fastest between worlds.
