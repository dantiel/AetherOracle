The Aetherverse

One lineage.
One aether.

The Aetherverse is not a portfolio of disconnected tools — it is a single idea expressed across platforms: a reasoning substrate with a voice, a memory, and a council of specialists. What began as an editor plugin grew, without changing its nature, into a distributed oracle.

The philosophy

The aether is the reasoning substrate — the calculating space where the model actually thinks. Everything in the Aetherverse is an expression of that one invariant:

One oracle

Every turn resolves to POST /aether/invoke on some host that carries the core. There is no client/server split — there is only the aether.

Pythia is its voice

The companion is an identity, not an interface. The same familiar speaks in the editor panel, on iOS, and in the terminal.

The aether is everywhere

Install the core on any OS and it becomes an Aether OS — hermetically in sync with one and only one aether.
