The task engine · ten alchemical steps

Magnum Opus.
The Great Work, Staged.

A complex prompt becomes the alchemical work: research, options, detail, analysis, patches, tests, edge cases, audit, documentation — ten steps, tracked, retried and inherited by subtasks. And above the engine, Salomo's seals turn goals into ordered milestones.

▲ The engine

Tasks run as step sequences with per-step guidance, temperatures and thinking depths, previous results always visible to the current step.

◈ Workflow shapes

full = all 10 alchemical steps · analysis = 5 steps · simple = 3 steps · debug = step through every phase without executing tools — the plan crystallizes before the first tool call.

◈ The ten steps

Generate solution options → evaluate the task → task detail → choose the best option → analyze files → apply patches → run tests → validate edge scenarios → audit and optimize → update documentation. Each step stores its result; each may retry up to three times.

◈ TaskLedger

create_task, execute_task, evaluate_task, update_task, list_tasks, remove_task. States: pending, active, paused, failed, completed, invalid, cancelled.

◈ Subtasks & inheritance

Tasks can spawn subtasks (depth-bounded); a subtask inherits its parent's context — the child wakes inside the parent's room, not in a vacuum.

▲ Seals — Salomo's executive ledger

The king decomposes the great work. A seal is a goal plus an ordered list of milestones, each a real engine task, each optionally gated on earlier milestones and owned by a companion.

▲ seal_create

Goal + milestones with depends_on edges (0-based indices). Ungated milestones run in parallel; depends_on: [i-1] builds a strict chain.

▲ seal_run

Drives the critical path: executes the next unblocked milestone and re-evaluates, hermetically bounded (max steps per turn) — never a runaway loop.

▲ seal_delegate

Each milestone can be owned by a companion glyph — the fox takes the clever path, the wolf the radical cut, the owl the architecture. seal_status shows the computed next action.

seal_create goal: "Ship the cartography",
milestones: [
  { title: "Delta memory", owner: "owl" },
  { title: "Sync rite",    owner: "drache", depends_on: [0] },
  { title: "Docs",         owner: "schwan", depends_on: [1] }
]
