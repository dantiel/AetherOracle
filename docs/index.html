Distributed by design

One brain, many shells. A pure-stdlib link tier discovers oracle peers on the LAN and routes turns to them. There is no client/server split — the aether has no split.

Install

Any OS with Ruby ≥ 3.1. The gem pulls the full brain tier and its dependencies automatically — precompiled native binaries included, no Rust or source build required.

gem build aetheroracle.gemspec
gem install ./aetheroracle-1.0.0.gem

aether veil          # first-run system check + guided config
