Cartography · the project's living map

Arsara.
The Cartographer.

A project is read once, woven into memory, and then kept alive: every change re-sights the touched files, every sync glows in the transient cascade, and every worker whispers its deltas to its siblings.

The delta memory

The cartographer never re-scans blindly. corpus_sightings remembers a mtime:size fingerprint per file; corpus_meta holds last_sync_at. A sync compares, re-sounds only what moved, and excises what vanished.

corpus_sound

The first contact: a full Argonaut sounding of the repository into the corpus graph, followed by the map weaving. Idempotent — wipes and rebuilds.

project_sync

The incremental rite. Unions git status --porcelain with the fingerprints — catching same-size same-second edits and concurrent workers — then re-sounds added/changed files only.

auto-observe

Edits made by the oracle itself (create_file, patch_file, rename_file) re-sight the path automatically the moment the tool succeeds. mnemosyne_observe covers host-editor edits.

The map notes

After every sounding and sync, Arsara (re-)mints compact durable notes under the map tag: one overview plus one note per project area — files, symbols, sample files and a one-line description written by the kopist (fast model) when available, else a heuristic.

The transient weaving — fused with the cascade

corpus-delta fragments

Every touched file mints a Stufe-2 fragment (Δ added/changed/removed …, TTL 3600 s). The change glows fresh in recall and decays into the substrate — exactly like a working thought.

sync-marker — the cross-worker whisper

Every sync with a delta mints one marker fragment (sync-marker GAMAYUN-WIN:39544 @ 22:00: +0 a, 24 c, -1 r). Sibling AetherOracle workers sharing the memory db feel it through their normal fragment recall — no polling, no re-scan. busy_timeout = 5000 keeps concurrent writers polite.

promotion hook

After every sync the ladder checks in with Ouroboros: paths glowing repeatedly are lifted into durable structure notes.

configuration
