Pythia CLI

The voice,
in your terminal.

Pythia is not a client — it is an identity. The Dialog-Kammer is the polymorphic, hermetically interactive terminal where the oracle speaks. Built for real human flow: it preserves your draft, keeps your focus ring, and renders live working overlays while the oracle reasons.

A terminal that respects the craftsperson

A CLI is where precision matters most. Every keystroke edge-case was hardened so the tool never gets in the way.

Draft-preserving history

Scroll up through previous inputs, then back down — your in-progress prompt is restored, not discarded. Accidental arrow taps never erase what you were writing.

Full key fidelity

DEL works, extended scan-codes are honored, and UTF-8 multibyte input (umlauts, accented characters) is reassembled byte-by-byte — so ä is ä, not a mangled codepoint.

Non-blocking work

The oracle reasons in a background thread while the console stays responsive — Tab/Shift-Tab cycle the focus ring, and a minified overlay shows progress without freezing input.

Live intermediary blocks

As the oracle works, intermediary thoughts render as -- ~ -- blocks in cyan — the reasoning is visible in flight, with the full answer once at the end.

Configuration

Only a model is needed. Pick a known model and the fast model, API type, and endpoint are derived automatically; for a custom model, fill the minimal fields directly.

# ~/.aethercodex
model: deepseek-chat     # known model → everything else is derived

# --- custom model: minimal fields ---
# model:    your-model-id
# api-type: openai       # openai | anthropic | gemini | deepseek
# api-url:  https://api.example.com/v1/chat/completions
# api-key:  sk-...       # or export AETHER_API_KEY=...
