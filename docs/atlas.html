Atlas.
The Titan who carries the map.

Complete project mapping, woven into living memory. A project is read once, kept alive by delta memory, and every change glows in the transient cascade — while sibling workers whisper their deltas to each other through the shared æther.

⬡ The map at a glance

After every sounding and sync, Atlas (re-)mints compact durable notes under the map tag: one overview plus one note per territory — files, symbols, sample paths, and a one-line description written by the kopist (fast model) when a distinct fast model exists, else a heuristic. The map is the landing strip for recall: atlas_map reads it in one pure query, no DB writes — then recall dives into the territory that matters.

⋈ Three rites of reading

How a project enters memory, and how it stays alive.

⋈

corpus_sound — the first contact

A full Argonaut sounding scans every source file into corpus_nodes (files + symbols) and corpus_edges (imports · nesting · defines), indexes the token substrate, then Atlas weaves the map. Idempotent — wipes and rebuilds.

◈
⇄

project_sync — the incremental rite

Unions git status --porcelain with the mtime:size fingerprints of the delta memory — catching edits invisible to fingerprints, e.g. same-size same-second writes or concurrent workers. Re-sounds only what moved, excises what vanished. First run falls back to a full sounding.

◈
⎇

auto-observe — memory in the act

Edits the oracle makes itself (create_file, patch_file, rename_file) re-sight the path the moment the tool succeeds — the memory is minted in the act. mnemosyne_observe covers host-editor edits. Sync is then rarely needed.

◈

⋄ The weaving — fused with the cascade

The transient Mnemosyne cascade mirrors the project's living change.

⋄

corpus-delta fragments

Every touched file mints a transient fragment (Δ added/changed/removed …, TTL 3600 s). The change glows fresh in recall and decays into the substrate — a working thought of the project.

◈
⇄

sync-marker — the cross-worker whisper

Every sync with a delta mints one marker fragment (sync-marker GAMAYUN-WIN:39544 @ 22:00: +0 a, 24 c, -1 r). Sibling workers sharing the memory db feel it through normal fragment recall — no polling, no re-scan. busy_timeout = 5000 keeps concurrent writers polite.

◈
⌁

promotion hook

After every sync the ladder checks in with Ouroboros: paths glowing repeatedly are lifted into durable structure notes — the fragment becomes a note.

◈

⚙ Configuration

The cartography: section of .aethercodex — all defaults on, flip per project.

# .aethercodex — cartography (Atlas)
cartography:
  auto-map: true           # re-mint map notes after every sound/sync
  delta-fragments: true    # glow fragments for touched files
  fragment-ttl: 3600       # half-life of the glow (s)
  map-flash: true          # kopist writes one-liners (distinct fast model)
  git-track: true          # union git status with the fingerprints
  observe-edits: true      # auto re-sight after agent tool writes
  sync-marker: true        # cross-worker whisper fragment
