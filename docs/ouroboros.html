Ouroboros.
Intelligent Recall & Promotion.

The serpent eats its own tail: memory recalling memory, distilling itself, and lifting the transient into the durable. Two rites — the digest and the ladder.

The digest — intelligent recall

ouroboros_recall runs the normal Mnemosyne recall, then flash-synthesizes the matches into one compact current-state digest: duplicates merged, historical and transient matter dropped. The deep mind reads one living summary instead of N raw fragments — the kopist writes, the master interprets.

# returns { digest:, notes: }
digest: "Concurrent-Worker-Modell: shared memory_db, sync-marker whispers,
         busy_timeout 5000. Files: corpus.rb, arsara.rb."
notes:  [ the raw matches, for when the deep mind wants the source ]

Without a distinct fast model the digest is simply nil and the raw notes remain — no cost, no surprise.

The ladder — promotion made live

The first rung of the documented cascade fragment → note is now real:

1 · observe

After every sync with a delta, the ladder counts active sync-markers per path. A file that keeps changing keeps glowing.

2 · threshold

Three glows (configurable) and the path is lifted: one durable structure note — Repeatedly active: ruby/mnemosyne/corpus.rb — corpus: 444 nodes (method:15, …) — carrying the current corpus summary. Markers are consumed.

3 · guards

Idempotent: a path already carrying a promoted note is skipped. And a path that no longer exists on disk is never promoted — the ladder lifts the living, not the dead.

# .aethercodex
ouroboros:
  synthesize: true                      # digest recall results via flash
  promotion: { enabled: true, threshold: 3 }

Promotion is pure DB work — no flash model needed. The manual rite is mnemosyne_promote.
